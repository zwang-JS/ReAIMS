ReAIMS preview harness

Static stand-in for CityU AIMS (Ellucian/SunGard Banner 8.x Self-Service). Open over file:// with no server and no extension. Append ?theme=light or ?theme=dark; with no valid parameter data-reaims-theme is absent, which is the "follow the OS" state.

Cascade order is deliberately inverted: our 8 stylesheets load before Banner's web_defaultapp.css, reproducing how Chrome applies injected content-script CSS ahead of the page's own <link> elements. Do not "correct" it.

Requires python tools/preview/fetch_vendor.py to have been run: vendor/ is third-party material and is gitignored. If Banner's stylesheet is missing, a red banner appears at the top of this page — without it the cascade check is not happening.

Only its <script> blocks were removed; the Google analytics tag and the session-timeout poller must not run in this harness.
